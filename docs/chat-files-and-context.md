# 附件与上下文

## 文件和图片

Web 的项目、管理和 Agent 测试聊天可以添加文件、拖入文件或粘贴图片。上传完成后再发送；附件会显示文件名，点击图片放大预览，文件通过下载链接保存。

CLI 使用 `/attach /path/to/file`，随后发送分析问题；`/detach` 清空待发送附件，不删除文件。相对路径以启动目录为准，路径包含空格时可加引号。通过 SSH 运行 CLI 时，这是远端机器的路径；电脑上的文件需先用 scp/SFTP 传到远端，或通过 Web 上传。

- CLI 引用原文件，不复制整个目录；仅支持普通文件。
- Web 上传保存在当前实例的 `tmp/attachments` 目录，返回受管理接口保护的附件链接。重启后仍可读取，不自动清理已经引用的附件；删除该目录下的附件会使对应历史链接失效。
- 上传文件在执行时复制到工作目录 `.carbot/tmp/`（命名实例为 `.carbot_<别名>/tmp/`），本次执行结束后清理副本；实例数据目录中的原件继续用于历史会话。
- 单文件最多 10 MiB，图片最多 5 MiB；一次上下文最多 8 个附件、总计 20 MiB。日志记录链接，不嵌入 Base64。
- UTF-8 文本提供首段内容及文件路径，剩余内容可由工具读取；PDF、Office 等二进制文件需要 Agent 使用适当的解析工具，不会伪装成已经提取文本。
- PNG/JPEG/GIF/WebP 图片使用模型原生图片输入。Carbot 支持 Chat、Responses、Anthropic 协议；Codex 使用图片参数，Claude 使用结构化输入。需要对应模型支持视觉；Mock 只用于验证流程，不会识图。
- 选中并发送附件意味着允许当前会话读取该文件，并交给所选模型分析；不会因此开放整个目录。命令执行仍遵循权限策略。

附件只属于当前 Carbot 实例。本次未增加跨 Carbot 的附件自动转发；组网中的远端 Agent 无法解析另一实例的本地附件 ID。远端 Web 可沿用 SSH 端口转发访问，不改变原来的本机管理访问限制。

## 智能压缩

在 Carbot 运行器的 Agent 配置中，将“压缩策略”选为“智能压缩”，或者配置 `CONTEXT_STRATEGY=intelligent`。现有首尾摘录、近期窗口和禁用选项保留，不自动修改已有 Agent 的选择。Codex/Claude CLI 自身的压缩仍由各自运行器负责。

接近配置的上下文长度时，Carbot 使用当前模型生成结构化摘要，记录目标、约束、决策、完成事项、待办、风险和引用，保留能放入窗口的近期完整对话块以及当前请求。较大的旧内容分块合并摘要；这会产生额外模型请求和费用。摘要失败、格式错误或长度不合适时，不会用无效摘要覆盖当前上下文。

摘要是有损的，不保证每个细节都保留。原始 JSONL 不改写，摘要检查点也写入日志；模型可以调用 `history_read` 回查当前会话。此工具不允许指定其他项目、会话或任意磁盘路径。

先传 `{}` 获取日志文件列表和行数，再按需查询：

```json
{"file":"hour-000000500000.jsonl","from_line":120,"to_line":180}
```

行号从 1 开始、两端包含，一次最多 200 行；结果体有大小限制，超大单行会标明截断和字节位置。`block` 是压缩时的逻辑对话块，不与物理文件行号混用。

读取使用每 128 行一个字节偏移索引，加上“文件 → 行号 → 内容”缓存。每个文件内容缓存最多 512 KiB / 512 行，最多保留 16 个文件的索引及缓存；追加保留旧行，截断、替换或检测到同长度改写时失效。缓存只是加速层，进程重启后重新建立，不维护超大聊天 JSON。

人工查询接口也支持同样的行范围：

```text
GET /v1/repl/{namespace}/chats/{group-or-admin}/logs/files/{file}?from_line=120&to_line=180
```

工具执行进度在 Web 和 CLI 中使用单行状态；Web 点击展开详情，CLI 使用 `/tools [序号]`。权限确认仍单独展示，不会被轮播隐藏。
# 浏览器与执行时长

内置 `browser-automation` Skill 默认使用 Puppeteer；在 Skill 目录运行 `node install.mjs`，依赖和匹配的 Chrome Headless Shell 安装到其 `.runtime`。此目录不随 release 打包，目标机器首次使用需要安装 Node.js/npm 并执行安装脚本。浏览器使用临时独立配置，不复用个人 Chrome 数据。

浏览器通过 `browser_run` 读取网页和截图，使用固定 Puppeteer 桥接脚本。Carbot 不再套外层系统沙箱，Chromium 自身沙箱仍保留。普通命令、Python 和 Skill 同样直接在本机执行，仍受操作确认和启用策略控制。

Agent、群聊和 A2A 任务不再设置固定 600 秒总执行时长。主动停止、单次模型请求超时和单条工具命令的超时仍保留。

## 在聊天中展示生成的图片

Agent 可调用 `image_show`，参数为 `{"path":"/工作目录/.carbot/tmp/截图.png"}`。只接受当前工作目录对应实例 tmp 下的本地 PNG/JPEG/GIF/WebP 图片，最大 5 MiB；不接收 URL，不发起 HTTP 请求，拒绝目录穿越和指向 tmp 外的符号链接。浏览器截图也自动返回相同图片引用。

工具返回 preview_url 和 reference；Agent 原样引用 reference，Web 即显示缩略图，点击可放大，另有下载链接。这是给用户展示图片，并不意味着模型已分析图片内容。

服务器保存一份不可变附件快照，使用已有附件 ID 接口提供内容，不开放任意路径下载接口。预览链接为相对路径，Web 自动使用当前连接的 Carbot 地址，无需配置公开 host。自定义域名通过反向代理访问 Web 即可；链接仍受原有访问控制，不是匿名公网分享链接。

这些文件不再写到工作目录根部。已有旧截图不自动移动或删除，避免破坏历史引用。
